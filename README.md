# Офіційне джерело

Статичний багатосторінковий сайт-каталог офіційних сайтів брендів, підготовлений для GitHub Pages.

## Запуск на GitHub Pages

1. Створіть новий репозиторій.
2. Завантажте весь вміст цієї папки в корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У блоці **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main`, папку `/ (root)` і натисніть **Save**.

## Файли

- `index.html` — головна сторінка;
- `catalog.html` — каталог із пошуком, фільтрами й сортуванням;
- `brand.html` — приклад сторінки бренду;
- `categories.html` — категорії;
- `countries.html` — країни;
- `verify.html` — методика перевірки;
- `submit.html` — форма додавання бренду;
- `about.html` — про проєкт;
- `404.html` — сторінка помилки;
- `data.js` — демонстраційні записи брендів;
- `script.js` — навігація та інтерактивність;
- `style.css` — усі стилі сайту.

## Важливо

Записи брендів у цій версії є демонстраційними. Перед публічним запуском потрібно повторно перевірити домени, регіональні версії, статуси компаній і дати.
